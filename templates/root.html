Backwerust Template

A starter template for building fullstack SSR-first web applications

Rust - backend language
axum - HTTP router
sqlx - SQLite driver and migrations
minijinja - Jinja HTML templating
Datastar - hypermedia
SSE-driven DOM patches - the server keeps rendering HTML, the browser swaps it in
TailwindCSS - CSS utility classes
No custom CSS files - responsive, dark mode, and design system out of the box
Bun - web asset bundling
Fast all-in-one JS runtime - replaces webpack, rollup, and esbuild
Lit - web components
Custom StyledLitElement base class enables shadow DOM components to share your Tailwind stylesheet
